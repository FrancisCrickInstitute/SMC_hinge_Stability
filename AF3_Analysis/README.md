# Cohesin Smc1–Smc3 hinge interface strength across species


## 1. Files

Figures: `fig1_state_landscape.png` (open/closed sampling vs crystals), `fig2_closed_strength.png` (closed-state strength, reliable models), `fig3_filter_comparison.png` (three filter regimes side by side). Earlier unfiltered views: `fig_boxplots.png`, `fig_heatmap.png`.

Data: `master_metrics.csv` (400 models × all metrics + ipSAE, state, reliability flags), `experimental_metrics.csv` (crystal pairs), `af_confidence.csv`, `struct_metrics.csv`. Stats: `stats_kruskal.csv`, `stats_dunn.xlsx`.

Reliability flags in `master_metrics.csv`: `reliable_ps` (per-species), `reliable_glob` (global ipSAE ≥ 0.66); `state` = open/closed; `iface_spread`, `edens` (energy density).
